# Python Automation Scripts

A collection of Python automation tools built for real-world use.

## Projects

### ATM Machine (ATM.py)
Interactive banking simulation with deposit, withdrawal and balance checking.

### Grade Reporter (Grade.py)  
Collects student data and generates Excel reports with pass/fail results and class average.

### Quotes Scraper (Quotes Scrapper.py)
Scrapes quotes.toscrape.com across all pages and saves to Excel with author statistics.

## Skills Used
- Python, openpyxl, BeautifulSoup, requests
- Excel automation, web scraping, file handling
